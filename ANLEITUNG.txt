============================================
  TEXT PROMPTER - Portable Version (Windows + Linux)
============================================

Für ANWENDER:

Node.js ist NICHT nötig - alles ist schon dabei.

 Anwender: doppelklickst du "Windows-start.bat"
  - Ein schwarzes Fenster öffnet sich kurz
  - Dein Browser öffnet automatisch:  http://localhost:8080
  - Fertig! Die Dokumente erscheinen.

 Anwender: Doppelklick auf "Linux-start.sh"
  - Terminal öffnet sich, der Browser öffnet automatisch:
    http://localhost:8080
  - Tipp: ggf. erst  "chmod +x Linux-start.sh"  einmalig ausführen.

Zum Beenden:
  - Browser-Fenster schließen
  - Das schwarze Fenster / Terminal schließen (oder dort Strg+C)

WICHTIG fürs Speichern:
  - Das schwarze Fenster / Terminal muss am Laufen bleiben,
    solange du die App benutzt.

--------------------------------------------
Für den GEBER (einmalig zusammenstellen):
--------------------------------------------

Diese Dateien gehören zusammen und müssen alle im GLEICHEN
Ordner liegen (ist bereits erledigt):

  Text_Prompter_Portable/
  ├── Windows-start.bat      <-- Windows: doppelklicken
  ├── Linux-start.sh         <-- Linux:   doppelklicken/starten
  ├── index.html
  ├── dokumente_anzeigen.html
  ├── dokumente/             <-- enthaltene .md-Dateien
  ├── generator/             <-- Server & Bibliotheken (server.js, marked.js usw.)
  └── node/
      ├── win/               <-- portables Node für Windows (nur die nötigen Binaries)
      │     ├── node32.exe   <-- für Windows 32-Bit (x86)  [wird automatisch gewählt]
      │     └── node64.exe   <-- für Windows 64-Bit (x64)  [wird automatisch gewählt]
      └── linux/             <-- portables Node für Linux (nur das nötige Binary: bin/node)

Welches Windows-Node eingesetzt wird, erkennt Windows-start.bat selbstständig
anhand der System-Architektur (32-Bit -> node32.exe, 64-Bit -> node64.exe).
Beide Dateien einfach im Paket belassen - es funktioniert auf jedem Rechner.

Weitergeben: Den gesamten Ordner z. B. als ZIP verschicken.

HINWEIS (Fehler "Port 8080 belegt"):
Falls beim Start eine Fehlermeldung mit "EADDRINUSE" erscheint,
läuft der Server schon einmal. Einfach das andere Fenster/Terminal
schließen und erneut starten.

--------------------------------------------
FEHLERSUCHE / TROUBLESHOOTING
--------------------------------------------

Linux: "Doppelklick auf Linux-start.sh macht nichts"
  - Linux führt .sh-Dateien beim Doppelklick meist NICHT aus.
  - Im Terminal ausführen:
      chmod +x Linux-start.sh node/linux/bin/node
      ./Linux-start.sh
  - Falls der Browser nicht automatisch öffnet: manuell
    http://localhost:8080/dokumente_anzeigen.html aufrufen.

Windows (Tablet, 32-Bit): Browser meldet "Kontakt zum Browser verloren"
  - Der Server läuft weiter; Seite einfach neu laden (F5).
  - Auf Tablets mit wenig RAM kann der Browser-Renderer unter Last
    (z. B. großer Editor oder Backup) neu starten. Tipp:
      - Nur das nötige Set öffnen, nicht alle Dokumente auf einmal.
      - Backups auf dem Desktop-PC erstellen, nicht auf dem Tablet.
  - Falls der Server abstürzt (Heap-Fehler): in Windows-start.bat den
    Wert --max-old-space-size=512 (32-Bit) auf 768 erhöhen
    (nur bei mind. 2 GB freiem RAM).
